### E-003：长报告流式输出产生事件风暴，前后端逐步卡顿

- 错误现象：长文本生成时把每个 token 都作为独立 SSE 事件发送，事件数快速膨胀，队列堆积，前端更新频率过高。
- 触发场景：Deep Research 输出投资研究报告、长篇总结或多 agent 连续产出内容时。
- 风险：流式体验抖动、内存压力上升、消息延迟增加，极端情况下可能让用户误以为系统卡死。
- 新增约束：SSE 层必须对连续 token 做聚合；事件队列必须设置上限；非 token 事件发出前要先刷新积压 token，保持顺序稳定。
- 放置位置：`quantum-chat-backend/api/deep_research.py`、`quantum-chat-backend/tests/test_deep_research_stream.py`
- 状态：已生效
