# 市场情报

先用私有新闻与结构化信号建立事实底座，再用 Web 搜索补全最新信息。

## 核心流程

1. 先查私有新闻库与结构化市场数据。
2. 涉及“最近 / 最新 / 近期”时，先确定精确时间窗。
3. 优先使用批量 Web 搜索，而不是连续串行搜索。
4. 区分：
   - 已验证事实
   - 新进入者 / 早期公司
   - 待核实弱信号
5. 工具结果里已有 URL 时，必须在输出中保留。

## 新玩家补充规则

凡是涉及以下意图，额外调用 `fetch_latest_company_promotions()`：

- 新玩家
- 新进入者
- 最近成立公司
- 早期团队
- 中国生态梳理
- deal sourcing

这条接口的作用是补充“近三个月注册且近期被新闻报道”的公司信号。

使用要求：

- 把它当成结构化新玩家补充源，不替代常规新闻检索。
- 把接口结果放入“新进入者 / 新公司 / 早期团队”部分。
- 不要把这些公司和头部玩家混在一个主表里。

## 输出要求

- 市场问题至少区分：
  - 头部玩家
  - 新进入者 / 早期公司
  - 待核实弱信号
- 融资事件优先保留时间、轮次、金额、投资方、来源 URL。
- 如果某条事实没有可点击链接，就只能进入“待核实”部分。
- 不要写“news-market 子Agent没有具体URL”这种笼统说明。
