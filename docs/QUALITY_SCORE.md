# 质量评分

## 用途

这份尺子用于判断改动、研究输出和 Harness 行为是否足够好。

每个维度按 0 到 3 分打分。

## 维度

### 1. 任务贴合度

- `0`：解决错了问题
- `1`：部分相关，但没抓住主问题
- `2`：基本解决，有少量缺口
- `3`：准确解决问题

### 2. 上下文纪律

- `0`：上下文杂乱，明显乱读
- `1`：信息过载，焦点分散
- `2`：上下文基本合适，仍有少量冗余
- `3`：在正确时机读取了正确粒度的信息

### 3. 约束遵守

- `0`：违反关键约束
- `1`：部分遵守，但突破重要边界
- `2`：大体遵守
- `3`：模式、边界、合约都很清晰

### 4. 可观测性

- `0`：过程几乎不可见
- `1`：只能看到结果
- `2`：部分可见
- `3`：规划、执行、验证、产物都可检查

### 5. 可靠性

- `0`：脆弱，容易失控
- `1`：只有 happy path 可用
- `2`：基本稳健
- `3`：有清晰回退、错误可追踪、边界稳定

### 6. 产物质量

- `0`：没有留下可复用产物
- `1`：产物存在，但难以复用或追溯
- `2`：可复用，但需要清理
- `3`：可复用、可追溯、可持续积累

## 通过标准

- 约束遵守或可靠性出现 `0`，视为阻断项
- 好的改动通常每项至少 `2`
- deep 研究输出应尽量追求“可观测性”和“产物质量”为 `3`
