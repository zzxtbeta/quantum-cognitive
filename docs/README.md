# 文档索引

`docs/` 是这个项目的控制面文档区，不是杂项资料堆放区。

建议阅读顺序：

1. `../AGENTS.md`
2. `ARCHITECTURE.md`
3. `DESIGN.md`
4. 再按任务选择下面的专门文档

## 文件说明

- `ARCHITECTURE.md`：系统分层、目录边界、依赖流向
- `DESIGN.md`：上下文管理、约束设计、记忆和产物策略
- `PLANS.md`：当前阶段的基础建设计划
- `PRODUCT_SENSE.md`：产品意图、用户路径、工作台定位
- `QUALITY_SCORE.md`：质量评价尺子
- `RELIABILITY.md`：可靠性、观测、回退要求
- `SECURITY.md`：安全边界、秘密信息、输出约束
- `ENTROPY_MANAGEMENT.md`：Harness 自身的防腐化机制
- `HARNESS_ENGINEERING_BLUEPRINT.md`：长线蓝图

## 编写规则

- 内容用中文写
- 每份文档只回答一个核心问题
- 决策规则优先于背景描述
- 过时内容要及时删除，不要只做追加
