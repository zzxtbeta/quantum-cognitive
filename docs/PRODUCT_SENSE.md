# 产品意图

## 主要用户

这个系统主要服务需要做研究、判断、比较、追踪的人，而不是只想和 AI 随便聊天的人。

## 核心任务

系统应该帮助用户：

- 快速理解一个主题
- 在需要时升级成多步深度研究
- 看见过程，而不只是看见答案
- 反复回到旧研究继续推进
- 把一次研究转成可沉淀的认知资产

## 用户路径

### 1. 探索

用户先提出问题或进入一个线程。

### 2. 升级

如果任务复杂，系统应该切换到 deep 工作流，而不是继续假装它只是普通对话。

### 3. 检查

用户应该能看见：

- 哪个子代理在工作
- 调用了哪些工具
- 系统正在验证什么

### 4. 决策

结果应该足以支持真实判断，而不是只有一段漂亮但空泛的总结。

### 5. 复用

最终结果应留下可复用产物，成为后续工作的基础。

## 产品原则

- 可信的流程比花哨的回答更重要
- 有来源的深度比无来源的自信更重要
- 可沉淀研究比一次性聊天更重要
- 可见性比黑箱魔法更重要
